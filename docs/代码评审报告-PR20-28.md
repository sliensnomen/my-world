## 2. 高优先级

### 2.1 时间线 `note` 协议允许、实现报 CL103

```
[严重度: high]
文件:classlint/classlint.py:111
文件:judges/cl/structure.py:31
```

`classlint/PROTOCOL.md` §2.6 明确 `moment` / `shift` 的 `note` 可选，`timeline_schema_findings()` 也写了 `note` 类型校验；但 `TIMELINE_FIELDS` 把它排除了：

```python
TIMELINE_FIELDS = (TIMELINE_MOMENT_FIELDS | TIMELINE_SHIFT_FIELDS) - {"note"}
```

结果任何带 `note` 的时间线卡都会在 CL103 报“未定义字段”。实测 `moment` 与 `shift` 都复现。

**修法：** 去掉两处 `- {"note"}`，并在 `timeline-clean` 里补一个带 `note` 的夹具。

### 2.2 畸形 `demand` 会让 PE006 / PE014 直接崩溃

```
[严重度: high]
文件:classlint/classlint.py:963（PE006）
文件:classlint/classlint.py:1058（PE014）
文件:judges/pe/rules.py:325、:422
```

CL108 已经报告 `demand` 的键不是字符串，但 PE006 / PE014 仍然执行 `sorted(demand)`。混合键（如 `1` 与 `grain`）会抛：

```
TypeError: '<' not supported between instances of 'str' and 'int'
```

两套后端都会崩。这违反了「坏数据由 CL108 报，PE 不拿它下判」的口径。

**修法：** PE006 / PE014 遍历前只接受字符串键，或至少 `sorted(demand, key=str)`；补一个混合键夹具。

### 2.3 缺 `id` 的流量 + `surplus` 会让 PE004 崩溃

```
[严重度: high]
文件:classlint/classlint.py:708
文件:judges/pe/rules.py:125
```

`_flow_entries()` 不要求流量卡有 `id`；当实体声明 `surplus` 且这条流量被算进 `same` 时：

```python
", ".join(f.id for f in same)
```

会拿到 `None`，抛 `TypeError: sequence item 0: expected str instance, NoneType found`。CL101 已经报缺 id，但规则本身不应跟着崩。

**修法：** `_flow_entries()` 排除 `e.id is None` 的条目，或消息里统一 `str(f.id)`；补夹具。

## 3. 中优先级

### 3.1 legacy 的 `needs` 校验写了两遍

```
[严重度: medium]
文件:classlint/classlint.py:421
文件:classlint/classlint.py:435
```

同一段 `needs` 校验在 `flow_schema_findings()` 里重复。默认 Registry 后端只报 3 条 CL108，`WGP_JUDGE_BACKEND=legacy` 会报 6 条（每条重复一次）。双跑测试没抓到，因为现有夹具没有非法 `needs`。

**修法：** 删掉重复段，或抽成公共函数；加一个非法 `needs` 的双跑用例。

### 3.2 时间线 `when` 的双后端不一致

```
[严重度: medium]
文件:classlint/classlint.py:358
文件:judges/cl/structure.py（无对应校验）
```

legacy 在 `timeline_schema_findings()` 里校验了 `when`，registry 没有；而 `when` 又不在 `TIMELINE_FIELDS`，本来就会被 CL103 拒绝。结果带非法 `when` 的时间线卡：

- registry：只报 CL103。
- legacy：CL103 + CL109。

建议直接删掉这段死校验；如果确实要让时间线接受 `when`，必须同时补 `TIMELINE_FIELDS`、registry 校验和夹具。

## 4. 低优先级

### 4.1 `view` 标题未转义

```
[严重度: low]
文件:classlint/classlint.py:1552
```

`root.name` 直接替换进 `__TITLE__`，没有 HTML 转义。世界目录名可控时可在生成的 HTML 里注入标签。节点文本本身使用 `textContent`，这部分是安全的；建议标题也走 `html.escape()`。

### 4.2 `fork` 没有参数分隔与测试

```
[严重度: low]
文件:classlint/classlint.py:1580
```

`git branch name` 没有 `--` 分隔，也没有任何回归测试。建议改为 `git branch -- name`，并补一个 fork 用例。

### 4.3 PE004 对 flow 卡上的畸形 `surplus` 仍可能下判

```
[严重度: low]
文件:classlint/classlint.py:686-714
```

`surplus` 写在 `type: flow` 卡上时 CL103 已报非法，但 PE004 没有跳过 flow 条目，仍可能参与定量判定。建议与 PE005 一样跳过 flow。
