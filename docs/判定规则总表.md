# 判定规则总表

> **用途**：把 `canonlint` 与 `classlint` 的确定性判定收在一张表里，作为对照外部标准（如 CIDOC CRM 7.1.3）的跑分清单。
>
> **口径**：代码为准。本表核对到 2026-10-28 的工作区（协议 1.9 / 契约 0.7）。文档与代码不一致时，以 `canonlint.py` / `classlint/classlint.py` / `store/` 为准。
>
> **数量**：CA 核心 39 条 + econ 扩展 2 条 + CL 8 条 + PE 6 条 = **55 条**。
>
> **级别**：`error` 默认让退出码变 1；`warning` 默认不拦、`--strict` 下拦；`info` 只报告；`report` 只随 `--impact` 输出，永不进退出码。

---

## 1. CA1xx · 结构与格式（14 条）

| 编号 | 级别 | 判定条件（代码口径） | 需要模型提供 |
|---|---|---|---|
| CA100 | error | 文件无法解析：无 frontmatter、YAML 语法错误、frontmatter 顶层不是映射。 | Markdown 文件 + YAML frontmatter，可解析为键值映射 |
| CA101 | error | 缺顶层必填字段：`id`、`title`、`type`、`author`、`date`、`status`、`load_bearing`、`canon_refs`、`conflicts_with`、`ai_assisted`。`status: archived` 还必须有 `superseded_by` 键（值可为 `null`）。 | 每个实体具备固定字段集；生命周期字段 |
| CA102 | error（`x-` 实验值记 info） | 枚举值非法：`type` ∈ {location, faction, character, event, item}；`status` ∈ {draft, trial, canon, archived}；`layer` ∈ 八层；`stance` ∈ {official, heretic, unknown}；`event_kind` ∈ 十二种事件。`x-<命名空间>-<名称>` 形式的实验 `type`/`event_kind` 只记 info。 | 受控词表 + 扩展命名空间 |
| CA103 | error | `date` 必须是 `YYYY-MM-DD` 的真实日期；YAML 原生日期对象也收。 | 日期数据类型 |
| CA104 | warning | `status` 为 trial/canon 时，正文（剥代码块、HTML 注释、空白与标点后）少于 200 字。 | 正文文本与长度 |
| CA105 | error | `id` 不是字符串，或不匹配 `^[a-z0-9-]+$`。 | 稳定 ID 语法 |
| CA106 | error | 顶层字段不在字段表内，且不带 `x-` 前缀。 | 封闭字段词表 + `x-` 扩展 |
| CA107 | error | `depends_on` 项不是对象，或对象缺 `id`/`kind`/`critical`，或含非 `x-` 的未定义键（canonlint 口径；classlint 只要求 `id`）。 | 依赖断言对象：目标 + 类别 + 是否关键 |
| CA108 | error（`x-` 记 info） | `depends_on.kind` 不在 {resource, production, economy, fiscal, manpower}；`x-` 前缀记 info，其余 error。 | 物资类别词表 + 扩展命名空间 |
| CA109 | error | 类型/形状错误：关系字段非列表或元素形状坏；`load_bearing`/`ai_assisted`/`critical` 非 bool；`superseded_by` 非 id 字符串或指向自己；`when_sort` 非有限数字、`when` 非字符串；事件腿 `by`/`to`/`object`/`from`/`result` 非 id 列表；事件字段出现在非 `type: event` 的卡上。 | 各字段的数据类型与形状 + 事件卡类型门禁 |
| CA110 | warning | `relations[].type` 与某规范关系名去掉连字符/下划线后编辑距离 ≤1（如 `depends-onn`、`extractss`）：报疑似拼写错误，并**按规范名建边**照常判定。 | 规范关系词表 + 拼写守卫 |
| CA111 | warning | 旧写法 `depends_on` + `kind: legitimacy`：已归一为 `derives_legitimacy_from` 并照常判定，只提示改写。 | 关系迁移/废弃映射 |
| CA112 | error | YAML frontmatter 出现重复键（PyYAML last-wins，前一条会静默消失）。 | 序列化键唯一性 |
| CA114 | error | 两张卡使用同一个 `id`；按路径序首个进索引，被遮蔽者自己的出边仍检查。 | 全库 ID 唯一性 |

## 2. CA2xx–CA5xx · 内容、引用与链条（13 条）

| 编号 | 级别 | 判定条件（代码口径） | 需要模型提供 |
|---|---|---|---|
| CA201 | warning | 两条目正文相似度 ≥0.85（双方正文均 ≥100 字；`superseded_by` 承接对豁免）。 | 正文 + 相似度 + 降级承接关系 |
| CA301 | warning | trial/canon 条目的标题或正文命中承重墙关键词（经济、货币、税收、贸易、铸币、政治、政权、法律、继承、选帝、军队、征兵、战争赔款），但 `load_bearing` 不是 `true`。 | 关键词表 + 承重布尔标记 |
| CA302 | error | `load_bearing: true` 但缺 `layer`，或没有任何 `depends_on` 声明/边。 | 承重标记蕴含层级与依赖 |
| CA401 | error | 引用指向不存在的 id，或使用未支持的 `world:id` 形式。覆盖所有关系（含自定义关系名）、事件腿 `by`/`to`/`object`/`from`/`result`，以及 `custody_of`/`member_of` 断言。 | 全局引用完整性 |
| CA402 | error | `canon_refs` 目标状态是 draft/trial；或目标是 archived 且已有有效承接者（提示迁移过去）。archived 无承接者时不报，交给 CA405。 | 引用目标的状态门禁 |
| CA403 | warning | `conflicts_with` 双方都用简式且对方没有回指；对象式（带 `stance`）豁免。 | 对称矛盾关系 + 立场注解 |
| CA404 | error | `status: canon` 的条目，其 `depends_on` 目标状态不是 canon。 | 依赖目标的状态门禁 |
| CA405 | error | archived 条目仍被 `canon_refs` 引用，且没有有效承接者（字段缺、`null`、坏值、指向不存在、指向自己）。 | 降级/接替流程完整性 |
| CA501 | error | 承重墙条目的物质族 `depends_on` 目标层级序号高于自身（八层：geo→resource→production→economy→fiscal→military→political→ideology）。 | 八层顺序 + 依赖方向 |
| CA502 | error | 物质族 `depends_on` 子图存在环。 | 依赖图无环 |
| CA503 | warning | economy/fiscal/military/political 层承重墙条目没有任何物质族且 `critical: true` 的依赖（ideology 豁免）。 | 关键物质来源 |
| CA504 | report | `--impact <id>` 输出该条目的反向 `depends_on` 传递闭包（不含主体自身）。永不进退出码。 | 反向可达性 |
| CA505 | warning | 仓库级：存在 military/political 层承重墙，但全库没有任何 `layer: fiscal` 条目。 | 仓库级层级覆盖 |

## 3. CA7xx · 事件流水（12 条）

| 编号 | 级别 | 判定条件（代码口径） | 需要模型提供 |
|---|---|---|---|
| CA701 | warning | 事件 A 的 `depends_on` 指向事件 B，双方都有 `when_sort` 且 B > A（要求 B ≤ A，相等合法）。任一方缺 `when_sort` 豁免；同刻没有先后，id 只用于稳定输出。 | 事件时间序 + 事件间依赖 |
| CA702 | error | 完整事件必填腿缺失或为空：transfer/custody/grant 要 `by`+`to`+`object`；move 要 `object`+`to`；create/destroy/birth/death/modify 要 `object`；join 要 `by`+`to`；leave 要 `by`+`from`；transform 要 `object`+`result`。形状坏归 CA109，不双报。 | 事件腿 schema |
| CA703 | warning | transfer/grant 的 `object` 在此前没有任何持有者（无 `owns` 断言，也无更早的 transfer/grant）；事件缺 `when_sort` 豁免。`create` 不算持有来源。 | 所有权历史 / 期初状态 |
| CA704 | error/warning | 手写 `owns` 断言与流水推出的最终持有者不一致。多值 `to` 只放行最终那笔的受方；同刻多笔转让且受方集合不同时报“归属未定序”warning，不按 id 挑赢家；集合一致才继续 error 对账。 | 断言状态 vs 派生状态 + 同刻未定序 |
| CA705 | warning | 事件的 `by` 中有人在严格更早（`when_sort` 更小）的 death 事件里已死亡；同刻不算。death 事件自身也查，只豁免同一事件内的自环。 | 角色生死时间线 |
| CA706 | warning | `when` 与 `event_kind` 只给了一个（半截事件）；两个都不给是普通史料卡。 | 事件完整性标记 |
| CA707 | warning | 同一 `object` 被两张及以上卡片断言 `owns`；除派生状态按 id 序采用的第一个外，其余每张都报。与有无流水无关。 | 所有权断言唯一性 |
| CA708 | warning | 客体事件落在自身存在窗口外：create/birth 开窗，death/destroy 关窗，transform 关旧窗并为 `result` 开新窗；端点自身豁免，缺 `when_sort` fail-open。modify 是普通客体事件，不动窗口。 | 客体存在窗口 + 转化边界 |
| CA709 | error/warning | 手写 `custody_of` 断言与 custody 流水推出的最终保管人不一致；多值受方与 CA704 同口径，同刻多笔且保管人集合不同报“未定序”warning。custody 不改持有者。 | 保管断言 vs 保管流水 |
| CA710 | warning | 同一客体被多张卡断言 `custody_of`；派生展示按 id 序取第一个不是裁决，其余断言都报。 | 保管断言唯一性 |
| CA711 | warning | `move.from` 对不上链上当前位置。只查存在窗口内的 move；缺 `from`/`when_sort` 不查，多值位置未定则跳过。同刻先合并目的地，一致才确定，只有严格更晚的 move 才比对。 | 客体轨迹 + 同刻位置合并 |
| CA712 | error | 手写 `member_of` 断言，但该人对该组织流水里的最后动作是 leave；无流水不判，多组织合法。同刻 join 与 leave 并存时未定序，fail-open。 | 组织归属断言 vs join/leave 流水 |

## 6. PE · 政治经济学（6 条）

| 编号 | 级别 | 判定条件（代码口径） | 需要模型提供 |
|---|---|---|---|
| PE001 | error | A `extracts`→ B，但 A 对 B 没有 `controls`/`coerces`/`owns` 任一条边；B 不存在时不判（CL105 已报）。 | 抽取 + 控制/强制/占有基础 |
| PE002 | error（critical 依赖）/ warning（非 critical） | A `coerces`→ B 且 A `depends_on`→ B：若该依赖 `critical: true` 报 error，否则 warning。 | 强制关系 + 供养依赖 + 关键性 |
| PE003 | error | `legitimizes` 图的环状强连通分量（含自环）没有任何分量外输入边；有外部锚点的互锁合法。`derives_legitimacy_from` 会被物化成反向 `legitimizes` 一起判。 | 正当化关系 + 外部锚点 |
| PE004 | error | `extracts` 子图存在环（含自环）：剩余在循环中互相抽取、不落地于生产。 | 抽取图无环 |
| PE005 | warning | A `extracts`→ B，但 B 没有任何**物质来源侧边**：`extracts`、`exchanges_with`，或带 material kind 的 `depends_on`。裸 `depends_on` 不算。报在 B 侧。 | 再生产来源可见性 |
| PE009 | warning | A `owes`→ B，但模型里没有收账通道：B 对 A 有 `controls`/`coerces`/`extracts`/`legitimizes`，或 A 对 B 有承重 `depends_on`（`critical: true` 或带 material kind）。裸 `depends_on` 不算。报在 A 侧。 | 债务 + 可执行通道 |

## 附录 A · 词表与必填形状

### A.1 八层链（CA501 的方向依据）

```
geo → resource → production → economy → fiscal → military → political → ideology
 0        1           2           3          4         5          6          7
```

承重墙条目的物质族 `depends_on` 只能指向**序号不大于自己**的层。

### A.2 `depends_on.kind`（CA108 的五值）

`resource` · `production` · `economy` · `fiscal` · `manpower`

`x-` 前缀是扩展命名空间：能存、记 info、不进 CA501/CA502/CA503 的链条判定。

### A.3 关系词表（契约 `x-relation-vocabulary` 的十一个规范名）

| 关系 | 含义 | 注解 |
|---|---|---|
| `canon_refs` | 叙事引用：说法以目标为依据；目标须为 canon | — |
| `conflicts_with` | 矛盾：两条设定不能同时成立（标注不是错误） | `stance` |
| `depends_on` | 物质依赖：目标断供，本条就塌 | `kind`、`critical`、`note` |
| `exchanges_with` | 交换/流通：互相提供东西，但不是承重 | `what`、`note` |
| `owns` | 占有：名义/法律上属于本条 | `note` |
| `controls` | 支配：能实际指挥目标 | `note` |
| `extracts` | 抽取：从目标取走剩余（地租、利息、贡赋） | `what`、`note` |
| `coerces` | 强制：用暴力或胁迫使目标就范 | `note` |
| `legitimizes` | 正当化：为目标提供正当性说法 | `note` |
| `derives_legitimacy_from` | 名分依据：本条的名分来自目标 | `critical`、`note` |
| `owes` | 债务：本条欠目标 | `what`、`note` |

`superseded_by` 是生命周期字段，不是关系词表成员：它指向降级后的承接条目。

### A.4 事件词表与必填腿（CA702）

| `event_kind` | 必填腿 |
|---|---|
| `transfer` | `by` + `to` + `object` |
| `custody` | `by` + `to` + `object` |
| `grant` | `by` + `to` + `object` |
| `move` | `object` + `to` |
| `create` | `object` |
| `destroy` | `object` |
| `birth` | `object` |
| `death` | `object` |
| `join` | `by` + `to` |
| `leave` | `by` + `from` |
| `transform` | `object` + `result` |
| `modify` | `object` |

事件字段：`when`（故事内时间，字符串）、`when_sort`（有限数字，可选的排序键）、`event_kind`，以及事件腿 `by`/`to`/`object`/`from`/`result`。`custody_of` 与 `member_of` 是断言字段，不是事件腿。缺 `when_sort` 一律 fail-open；同刻没有先后，id 只用于稳定输出。

### A.5 条目必填字段与状态机

- 必填：`id`、`title`、`type`、`author`、`date`、`status`、`load_bearing`、`canon_refs`、`conflicts_with`、`ai_assisted`
- 状态：`draft → trial → canon → archived`；`status: archived` 必须有 `superseded_by`（无承接者填 `null`）
- `type`：location / faction / character / event / item（`x-` 为实验类型）

## 附录 B · 退出码与开关

| 引擎 | 退出码 | 含义 |
|---|---|---|
| canonlint | 0 | 通过（或只有 warning） |
| canonlint | 1 | 存在 error；`--strict` 下 warning 也算 |
| canonlint | 2 | 用法/环境错误（如缺 pyyaml、`--dup-threshold` 越界） |
| classlint | 0 | 无 error |
| classlint | 1 | 存在 error |
| classlint | 2 | 用法/配置错误 |
| classlint | 3 | 有 PE 规则被 `rules: {PExxx: off}` 关闭；加 `--accept-disabled-rules` 才回到 0 |

- `info` 与 `report` 永不进退出码。
- CL 结构规则不可关闭；只有 PE 规则可在世界仓库的 `classlint.yaml` 里关闭。
