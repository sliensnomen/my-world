# 术语表

> 只收「读文档时会卡住」的词，按数据模型、判定、版本分组。
> 定义以代码和协议为准；这里只给第一次读够用的一层，细节点进链接。

## 数据模型

| 术语 | 一句话 | 第一次在哪见到 |
|---|---|---|
| **世界**（world） | 一个目录：canonlint 读 `entries/`，classlint 读 `codex/`，另有宪章与可选事件流水。两层目前不共用一个目录。 | [第一次读](第一次读.md) |
| **条目 / 卡**（entry） | 一张 Markdown：YAML frontmatter + 正文。`id` 是稳定标识，文件名可以改，id 不能随便改。 | [store/README.md](../../store/README.md) |
| **卡面** | 作者手写的部分（frontmatter + 正文），与判定结果、流水派生状态相对。 | [README.md](../../README.md) |
| **`type`** | 条目类型：`location` / `faction` / `character` / `event` / `item`。 | [判定规则总表](判定规则总表.md) CA102 |
| **`status`** | 生命周期：`draft` → `trial` → `canon`；退役写 `archived` 并用 `superseded_by` 指向承接者。 | [PROTOCOL.md](../../PROTOCOL.md) §3 |
| **承重墙**（`load_bearing`） | 显式声明 `true` 的条目，必须填 `layer` 并声明依赖（CA302）。不是自动推断；没声明就不承担链条义务。 | [PROTOCOL.md](../../PROTOCOL.md) §5.3 |
| **`layer`** | 八层链条：`geo → resource → production → economy → fiscal → military → political → ideology`。承重墙必须有。 | [PROTOCOL.md](../../PROTOCOL.md) §5.2 |
| **关系 / 腿**（relation / leg） | 条目间的有向边。`depends_on` 的 `kind` 是资源类别；事件卡的五条腿是 `by` / `to` / `object` / `from` / `result`。 | [PROTOCOL.md](../../PROTOCOL.md) §2 |
| **`canon_refs`** | 「我引用这些 canon 条目」的断言；目标状态不对会触发 CA402/CA405。 | [判定规则总表](判定规则总表.md) |
| **`conflicts_with`** | 对称矛盾断言，可带 `stance`（official / heretic / unknown）。 | [PROTOCOL.md](../../PROTOCOL.md) §2.2 |
| **`relations`** | 规范形关系数组，写成 `{type, target, ...}`；与 `canon_refs`/`conflicts_with` 二选一（CA101）。 | [PROTOCOL.md](../../PROTOCOL.md) §2.2 |
| **`derives_legitimacy_from`** | 名分依据：A 的正当性来自 B。PE003 会把它物化成反向的 `legitimizes` 一起判。 | [PROTOCOL.md](../../PROTOCOL.md) §4.5 |
| **事件流水**（ledger） | 用 `type: event` 的卡按 `when_sort` 排出状态变化；持有者、保管人、位置、组织归属由它派生。 | [事件流水设计](../设计路线/事件流水设计.md) |
| **`when` / `when_sort`** | `when` 是叙事时间文本，`when_sort` 是可比较的数字排序键。缺 `when_sort` 时，依赖时序的规则会跳过（fail-open），不是所有规则都跳过。 | [PROTOCOL.md](../../PROTOCOL.md) §2.6 |

## 判定

| 术语 | 一句话 | 第一次在哪见到 |
|---|---|---|
| **finding** | 一条判定结果：规则编号、级别、哪张卡、哪条消息。 | [第一次读](第一次读.md) |
| **级别** | `error` 让退出码变 1；`warning` 默认不拦、`--strict` 下拦；`info` 只提示；`report` 只报告、永不进退出码（CA504 与 `graph`）。 | [判定规则总表](判定规则总表.md) |
| **CA** | canonlint 的结构规则：48 条核心 + CA601/CA602 两条 econ 扩展。 | [PROTOCOL.md](../../PROTOCOL.md) §6.3 |
| **CL** | classlint 的结构规则：CL100–CL110，共 11 条。 | [classlint/PROTOCOL.md](../../classlint/PROTOCOL.md) |
| **PE** | classlint 的政治经济学规则：PE001–PE016，共 16 条。 | [classlint/PROTOCOL.md](../../classlint/PROTOCOL.md) |
| **判定器 / Registry** | 统一的规则加载与执行入口：`core-ca`、`core-cl`、`pe` 三个包；`econ` 仍需显式 `--pack econ`。 | [judges/registry.py](../../judges/registry.py) |
| **`--strict`** | 只改退出码，不改判定：同一份数据，普通模式与 strict 模式的 findings 逐字相同。 | [README.md](../../README.md) |
| **`--impact`** | 反向 `depends_on` 传递闭包：改这张卡会波及谁。主体不进自己的下游，输出是 `report`，不影响退出码。 | [判定规则总表](判定规则总表.md) CA504 |
| **`--pack econ`** | 启用 CA601/CA602（数值与参数越界）两条扩展规则；不加就不跑。 | [PROTOCOL-ECON.md](../../PROTOCOL-ECON.md) |
| **夹具 / 快照** | `tests/world-*` 是夹具世界；`tests/snapshots/` 是逐字节快照，证明输出没变。 | [CONTRIBUTING.md](../../CONTRIBUTING.md) |

## 版本与分支

| 术语 | 一句话 | 第一次在哪见到 |
|---|---|---|
| **协议版本** | `canonlint.py` 的 `PROTOCOL_VERSION`，当前 `1.33`；规则增删改按 §9.1 升号。 | [PROTOCOL.md](../../PROTOCOL.md) |
| **契约版本** | `world.schema.json` 的 `x-contract-version`，当前 `0.9`；条目字段形状的唯一来源。 | [world.schema.json](../../world.schema.json) |

| **2.0** | 文字世界模型：以事件为唯一事实源，正在转型，不是 1.x 的下一版命令。 | [CHARTER.md](../../CHARTER.md) |
| **spine** | 2.0 的 L0 事件账本：`spine/event.schema.json`（契约 0.1，14 字段）与 `spine/tests/`。 | [spine/README.md](../../spine/README.md) |
