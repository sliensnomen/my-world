## 三条约定（简单，但重要）

1. **关系还没定义完**。所以 JSON 里关系**原样给出**——名字不翻译、不判断；前端只按名字分组显示。

2. **不许自造假数据**。用我们导出的真数据（假数据会把两边一起带歪）。

3. **JSON 的字段清单是两边的合同**。我们改字段，测试会红；前端也不许自己加字段语义。

## 验收（机器能查，不靠眼睛看）

- 换一份真实世界的数据，前端**不改代码**，图能出来。

- 点任意一个条目，都能换成中心。

- 我们这边：字段清单变了 → CI 变红（现在还没有这条测试，我会加）。

## 关于"嵌入式的数据库"

现在是：世界仓库本身就是数据库，后端直接读它、吐 JSON。 等要做**表格 / 筛选 / 统计**时，再把同一份 JSON 灌进 SQLite（单文件、嵌入式、不用装服务）。 —— 先不急，先跑通第一条。
