# 世界模型设计（草稿）

**一句话**：这个世界要像**账本**一样记——记的是「发生了什么」，「现在是什么样」是算出来的。

这份文档是讨论稿，不是已经生效的规矩。里面没有代码。

---

## 1. 现在的问题

现在的每张卡，直接写的都是**结论**：

```
A 控制 B
A 欠 B
A 的名分来自 B
```

写结论有个麻烦：**结论没法判对错**。谁来说这条是错的？拿什么对？没有依据可查。

账本反过来做：先记下**发生过的事**，结论由事推出来。这样每条结论都能追一句「你凭什么这么说」，而且答得上。

（史书就是这么写的。《史记》记的是事，不是「刘邦控制天下」这张表。）

---

## 2. 三层

拿游戏存档打比方：

| 层 | 是什么 | 谁写 |
|---|---|---|
| **期初** | 开天辟地时就已经有的东西：世界有哪些地方、哪些势力、谁是谁 | 作者写，不解释来历 |
| **流水** | 一件一件发生的事，只往后加，不改旧的 | 作者写 |
| **现在** | 把流水从头走一遍得到的结果：现在谁控制谁、谁欠谁、谁是国王 | **算出来的，不用写** |

只有前两层是数据。第三层是算出来的答案——手写它，等于把小说的结局抄到开头。

---

## 3. 一笔账怎么写

每件事都要写清「几样东西」。拿冰火举例：

```
时间：五王之战前
事：铁王座把奔流城封给了徒利家
  转了什么：奔流城
  从谁手上：铁王座
  到谁手上：徒利家
```

按事的种类分，一共六组：

| 事 | 要写清 |
|---|---|
| 转移（买卖、赠送、封赏、继承） | 什么东西 / 从谁 / 到谁 |
| 交接（借、抢、托管、捡到） | 什么东西 / 谁交出 / 谁接手 |
| 移动（搬迁、行军、流放） | 谁或什么 / 从哪 / 到哪 |
| 造与改（建造、改造、写出来） | 造了什么 / 用什么造的 / 改变了什么 |
| 生与死（出生、死亡、建国、灭国） | 谁或什么 / 什么时候开始或结束 |
| 授予名分（加冕、封爵、赐姓、追谥、认证） | 谁授予 / 授予谁 / 什么名分 |

再加一组**参与**：谁参与了哪件事，在里面是什么角色（将军、杂兵、旁观者）。

最后这一组和「授予名分」那一组，是今天最缺的两样东西。

---

## 4. 一条死规矩：东西不能凭空出现

只有两组事可以凭空增减：

- **出生 / 建国**（凭空多出来）
- **死亡 / 灭国**（凭空少下去）

其他任何东西的来去，都必须写清从哪来、到哪去。

- 允许：`厄拉科斯在远古由沙虫活动形成`
- 不允许：`哈克南家拥有厄拉科斯`，而全本没有一处写「他们是怎么拿到的」

这条规矩就是防「无源之财」。

---

## 5. 时间

每件事都得有一个**故事内的时间**。不要求精确到日，可以写「第三纪中期」「五王之战前三年」。

现在卡上那个 `date`（比如 `2026-09-23`）是**文件日期**——谁什么时候写的，跟故事里什么时候没关系。规定卡上能写什么的那个文件（`world.schema.json`）里，**目前没有任何「故事内时间」**。

这是第一件要补的事，而且它得排在最前面：流水要有先后，没有时间就没有先后，没有先后就不是流水，是一张清单。

---

## 6. 能查出来的毛病

流水立起来以后，下面这些都能自动查。它们全是作者真会犯、而现在一条也查不出的错：

| 毛病 | 长什么样 |
|---|---|
| 账不平 | 有东西转出去了，没人接手 |
| 无源之财 | 它现在拥有某样东西，可没有任何「怎么得到的」 |
| **死人做活事** | 一个角色死了以后，还在参加后面的事（小说里最常见的硬伤） |
| 时序倒流 | 一件事发生在它所依赖的事之前 |
| 名分无源 | 有名分，但没有那次授予（加冕、赐封、追认） |
| 双花 | 同一个时候，一样东西有两个主人 |
| 结论与流水打架 | 卡上写「现在谁控制谁」，跟流水推出来的不一样 |

---

## 7. 作者可以偷懒

要求每个作者写完整流水，他写三天就跑了。所以要留个口子：

**可以只写结论，但必须标一句「这是我的断言，没有流水」。**

- 断言**不参加**「账平不平」的检查。
- 断言**要参加**「跟流水打不打架」的检查。流水里一出现相反的事，就报出来。

有这个口子，这套东西才用得下去。

---

## 8. 东西怎么放

- **一张卡 = 一个账户**：放这个角色、势力、地方**本身是什么**（名字、类型、身份、属性）。不放它进出的历史。
- **一本流水 = 一个文件**：放发生过什么。
- **「现在」不存**，是算出来的（也可以另存一份，方便查）。

**为什么流水不能写在各自的卡里**：一件事牵涉两方（谁给出、谁接手）。写在两边就重复了；重复就会打架——改了一边、忘了另一边。

---

## 9. 版本

流水可以从某个点**分叉**：

```
原著 ──┬── 事 1 ── 事 2 ── 事 3
       └── 事 1 ── 事 2′ ── 事 3′    （改编）
```

原著一条、改编一条、同人一条。这是史书数据库给不了我们、而搞原创角色的人**人人需要**的东西：黑历史版、重制版、联动版。

---

## 10. 跟现在那些规则的关系

- 现在编号 501 到 505 的那一族规则，管的是「承重链条讲不讲得通」，读的正是「结论」这一层。账本加的是**它下面那一层**，上面的不用动。
- **`owes` 那条规则（债务必须收得回来）是这条路的第一个脚印**：它已经在要求「结论必须有支撑」。账本模型只是把这个要求，从债务一条推广到每一条结论。

---

## 11. 分三步走

每一步都不动现有的边：

1. **加时间**：卡上加「故事内时间」（可空、可写区间、可写「不明」）；「事件」类的卡加上「谁参与 / 在哪 / 结果是什么」。
2. **加依据**：允许给「谁控制谁」这类结论标一句「依据是哪件事」。
3. **加规则**：把第 6 节那七条查出来。

---

## 12. 还没定的事

1. 期初那一层，是单独一份文件，还是就散在各自的卡上？
2. 流水是一份文件，还是按时间分段（一纪一个文件）？
3. 时间怎么表示：「第三纪 245 年」这种自由文本，还是规定死格式？我倾向自由文本，另外给一个可选的排序用的小标记——规定太死就没人填。
4. 已有的那几个示例世界（冰火、沙丘、魔戒），要不要补流水？还是只让新世界按新规矩写？
5. 「这是我的断言」这个标记，叫什么名字好？
