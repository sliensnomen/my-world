# 架构稳固性与嵌合度评审

> 状态：草案。评审结论锚定在 `a361dc6`（存储层判定口径显式化，2026-11-12 实测）；第 6 节的建议 P1–P3 尚未拍板，处置完成后本报告转历史或并入修复记录。
> 评审方式：全量人工阅读（canonlint.py、store/、judges/、classlint.py、serve.py、econ.py、ledger.py 与测试骨架），未做变异手术。六套回归在锚点提交上实测全绿：`tests/run_tests.py` 75 项、`test_schema.py` 12 项、`test_store.py` 30 项、`test_serve.py` 35 项、`test_docs.py` 15 项、`classlint/tests/run_tests.py` 31 个夹具世界。行号均为锚点提交的行号，随代码漂移。

## 1. 结论边界

- 稳固性判为「稳」：失败即结果、写入原子、判定吃无定义数据的口径有纪律，均有下文证据。
- 嵌合度判为「焊牢为主，一条缝贴着」：读卡层与契约词表是机器锁住的焊缝；双后端的词表常量目前只靠输出级双跑贴住。
- 本报告不修改任何判定与行为；建议项全部未实施，不构成变更承诺。
- 评审视角是仓库主侧的人工评审，不是独立第三方评审；不要把本报告读成签核。

## 2. 分层依赖（实测读出）

```
world.schema.json（契约，关系词表唯一真值）
        │ store/contract.py 严格加载：缺失/损坏 → ContractError → exit 2（#12）
store/parse.py ←—— canonlint 与 classlint 共用同一份读卡
store/{model,layout,write,policy}（#14：判定口径显式声明）
        │
ledger.py（流水原料：事件视图、派生状态；只算不发判语）
        │
canonlint.py ──┬─ legacy 后端：本文件内联 check_*（WGP_JUDGE_BACKEND=legacy 时）
               └─ registry 后端（缺省）：judges/{model,registry} → judges/ca/*（core 40 条 CA）
classlint.py ──┬─ legacy：RULES 注册表（PE001–015）
               └─ registry（缺省）：judges/cl/*（CL100–109）+ judges/pe/*
serve.py（标准库 HTTP；导出与写后审计走 canonlint.run 同一路径）
econ.py（扩展包单份真值；judges/econ_pack.py 是薄适配）
web/ + wgp-client.js（无框架薄前端）
```

## 3. 稳固性：守住的证据

| 守卫 | 证据（锚点行号） |
|---|---|
| 失败即结果，坏卡不隐形 | store/parse.py:296-304 把 `UnicodeDecodeError`/`OSError`/YAML 错误/递归爆栈都收成 `parse_error`；`_DuplicateKeyLoader` 把 YAML 重复键记成 CA112（store/parse.py:239-255） |
| 写路径原子与自检 | store/write.py:49-128 同目录临时文件 + `os.replace`、保留文件模式、拒只读、防写穿符号链接、清理 SIGKILL 残留；`cmd_link` 最小手术→`_verify` 重解析自检→失败退整块重排→再自检→拒绝写盘（write.py:546-560）；`flock` 防并发丢边（write.py:131-157） |
| 判定不吃无定义数据 | 缺 `when_sort` 不进流水（ledger.py:118-133）；同刻多笔一律「未定序」，id 序只用于展示（canonlint.py:636-650 的 CA704 口径） |
| 规则接线自动对账 | judges/ca/pack.py:231-239 用 `verify_schedule` 对账登记集与调度集；emit 时校验级别白名单（canonlint.py:1191-1218） |
| 契约不静默降级 | store/contract.py:132-168 缺失/损坏一律 `ContractError`，兼容模式必须显式 `WGP_COMPAT_VOCAB=1` 且带可见标记 |
| HTTP 攻面收敛 | serve.py:89-101 响应头注入防护；:494-510 `/api/raw` 防穿越 + 隐藏文件；默认只读、同源 + `application/json` + 可选 Bearer + JSONL 审计日志 |
| 确定性输出 | 扫描 `sorted()` 确定序（store/layout.py:49-72）；导出无时间戳、无绝对路径（canonlint.py:1072-1075） |

## 4. 嵌合度

### 4.1 焊牢的缝（有机器锁）

| 缝 | 锁 |
|---|---|
| 读卡只有一份实现 | test_store.py:868 用 AST 禁止 classlint 再定义 `ID_RE`/`FRONTMATTER_RE` 等名字；:1023 同一段字节两引擎建边逐条比对，唯一允许的分歧必须恰好是契约 `x-stricter-than-contract` 登记的那处 |
| 词表单源 | 关系词表、字段表、id 语法全部从契约与 store 读（`store.FIELD_TABLE`、`store/parse.py:82-103`）；canonlint 与 judges/ca 的 `KNOWN_FIELDS` 都取自 store，无人手抄 |
| econ 单源 | `econ.py` 是唯一实现，`judges/econ_pack.py` 只做登记与转发 |
| 规则不烂尾 | #13 日程对账：登记了没调度的规则直接报错（judges/registry.py:13-29） |
| 文档数字钉死 | `tests/test_docs.py` 把规则条数、检查项数、版本号钉到实测 |

### 4.2 贴着的缝（只靠输出级双跑）

双后端是三份完整实现：canonlint.py 内联版与 judges/ca/* 各一套，classlint.py 的 `RULES` 与 judges/cl/* + judges/pe/* 各一套。这是有意的恢复路径（`WGP_JUDGE_BACKEND=legacy` 紧急回退，见 `docs/代码评审报告-判定器注册表.md` 的「未完成前不得删除 legacy」），守卫是 run_tests.py:2641 起的族级双跑与 CLI/HTTP 全字节比对。但两份实现之间的**词表常量是字面量双抄**，双跑只在夹具恰好踩到那个值时才抓得住漂移：

| 常量 | canonlint.py | judges 侧 |
|---|---|---|
| `REQUIRED_FIELDS` | :52 | judges/ca/structure.py:11 |
| `VALID_TYPES`/`X_TYPE_RE`/`VALID_STATUS`/`VALID_STANCE` | :60-65 | judges/ca/structure.py:16-19 |
| `LAYERS`/`LAYER_INDEX`/`KIND_INITIAL_SET` | :66-73 | judges/ca/structure.py:20-23 |
| `WORLD_REF_RE` | :77 | judges/ca/refs.py:10 |
| `LOAD_BEARING_KEYWORDS`/`MIN_BODY_CHARS` | :80-83 | judges/ca/content.py:39-41 |

目前只有 `LAYERS` 被钉到文档（test_docs.py:227），常量级互钉不存在。

## 5. 次要缝

- serve.py:631 调 `canonlint._load_packs`——私有函数跨模块使用，名分上应转正。
- canonlint.py:7-8 的模块 docstring 与 AGENTS.md「判定层在 canonlint.py」的自述，落后于缺省 registry 半步：缺省下判定真身在 judges/ca/*。prose 未被 test_docs 钉住。
- serve.py `_index`（:540-558）把 `wgp_root.name` 未经 HTML 转义插进页面。风险低（目录名由服务启动者控制），但与 cmd_view 的转义做法不一致。
