## 4. 一个新人读完这 19 份，会不会做错事？

会，而且第一步就会。最该被改掉的那一句是：

> **`docs/接口说明.md:56`（以及 `:26`、`:43`、`给前端的说明:42`）：「把前端文件放进 `canonlint/web/`，然后开 `http://127.0.0.1:8000/web/index.html`。」**

照做 → 目录不存在 → `/web/index.html` 404；服务端 404 的 hint 还重复同一个错路径。新人会先怀疑服务，不会怀疑文档。

紧接着还有四句会让人做错：

1. `docs/给前端的说明.md:48`：「`python3 canonlint.py tests/world-arrakis --json`」看全量输出 → 拿到 `entries: 22` 的审计 JSON，误以为导出坏了。
2. `store/README.md:115-117` / `CONTRIBUTING.md:70`：「六个关系字段今天会被 CA106」→ 新人不敢用 `owns`/`owes`，或去「实现」一个已经实现的功能。
3. `PROTOCOL.md:57`、`:351-354`：「kind 六值含 legitimacy」→ 写了之后被静默改判成 `derives_legitimacy_from`，边图含义变了。
4. `classlint/PROTOCOL.md:49`：把关系名写成 `own` → 第一张卡就吃 CL103。

这四句的共同点：都不是代码 bug，而是文档在教人做一件代码不接受的事。按「静默失效是头号公敌」，它们比一条会崩的代码更危险。
