# 接口说明（`serve.py`）

只读接口：把世界数据交给前端。**它不是界面，也不做判定** —— 判定在 `canonlint.py` 里。

## 起服务

```bash
python3 serve.py tests/world-arrakis                 # 默认 127.0.0.1:8000
python3 serve.py ~/worlds/grey-harbor --port 9000 --pack econ
python3 serve.py --port 0                            # 让系统挑空端口，启动时会打印真实地址
```

- Python 自带，**不用装任何东西、不联网**。
- 默认只监听本机（要对外才加 `--host 0.0.0.0`）。
- **每次请求都重新读盘**：改完 Markdown 刷新页面就是新数据；不该被缓存的都不缓存。

## 路由

| 路由 | 给什么 | 备注 |
|---|---|---|
| `GET /` | 一页说明（条目/边/错误数量 + 路由表） | 给人和自检用，不是界面 |
| `GET /api/health` | `{ok, world, protocol_version, contract_version, counts}` | 存活与版本号 |
| `GET /api/world` | 整个世界（条目 + 边 + 词表 + findings + reports） | **与 `canonlint export` 的数据完全一致**（有测试钉死） |
| `GET /api/entry/<id>` | `{entry, relations}`：单个条目 + 进边和出边 | 查不到给 `404` |
| `GET /api/raw/<path>` | 世界目录里的原始文件 | 只读；不能穿越出世界目录 |
| `GET /web/...` | `canonlint/web/` 下的前端文件 | 同源，省掉 CORS |

## 例子

```bash
curl -s localhost:8000/api/health
curl -s localhost:8000/api/world | python3 -m json.tool | head -40
curl -s localhost:8000/api/entry/arrakis
curl -s localhost:8000/api/raw/entries/arrakis.md
```

## 规矩（都有测试守着）

- **只读**：`POST` / `PUT` / `DELETE` / `PATCH` → `405`。
- **不穿越**：`/api/raw/../canonlint.py` → `404`。
- **不露工具自己的东西**：隐藏文件与目录（`canonlint init` 会在世界目录里建 `.git`，里面有配置、钩子、索引）→ `404`。它们躺在「世界目录内」，所以只查穿越挡不住。
- **路径里的 NUL 字节** → `400`（不是断连）。`Path.resolve()` 遇到 NUL 会抛异常，以前没人接，请求方拿到的是空响应——分不清「没有这个文件」与「接口挂了」。
- **`/web/` 只取 `web/` 里的文件**：`/web/../` 折返、`..%2f` 编码写法一律 `404`；目录不存在时提示「把前端文件放进 canonlint/web/」。
- **不漏主机路径**：数据里只有世界仓库内的相对路径。
- **同一份数据两次请求字节一致**（没有时间戳、没有随机）。
- 响应头带 `Access-Control-Allow-Origin: *`（前端从别的端口取也能用），`Cache-Control: no-store`。
- 中文 id 记得 URL 编码（浏览器 `fetch` 与 `curl` 一般会自己处理）。

## 坏文件怎么办

读不出来的文件**也会出现在 `entries[]` 里**：`id` 是 `null`、`path` 指到它、`parse_error` 写着原因。
`/api/entry/<id>` 查不到它（它没有 id）——前端按 `path` 找它、灰着显示就行。

## 把前端放进来

把前端文件放进 `canonlint/web/`，然后开 `http://127.0.0.1:8000/web/index.html`：
和接口同源，不用管 CORS。`wgp-client.js`（仓库根）可以直接拷进去一起用。

## 解析器（`wgp-client.js`）

```html
<script src="/web/wgp-client.js"></script>
<script>
  WGP.load("/api/world").then(function (world) {
    var mm = world.mindmap("bene-gesserit");  // {center, branches:[{type, items:[…]}]}
    world.entries;      // 全部条目（补过默认值）
    world.neighbors("arrakis");  // 一个条目的进边 + 出边
    world.dangling;     // 指不到人的边（已标原因）
    world.broken;       // 读不出来的文件
    console.log(mm);
  });
</script>
```

它只做四件事：补默认值（缺字段、坏文件、重名）、建索引、给 `mindmap()`、标出指不到人的边。
**关系名原样用，不翻译、不判断**；字段名是两边的合同，不要自己加语义。
