# 作品层设计草案（works layer）

> 状态：草案，待姐夫审。2026-10-24。
> 一句话：**世界 = 事实（只存一次）；作品 = 视图（时间段 + 视角 + 分支声明）**。
> 分工（借 Pinakes 的词汇）：**工具管时间边界（horizon-safe），作者管知识边界（knowledge）**。

## 1. 解决什么问题

叙境社的交付物是「每人一篇署名作品」。没有作品层，六个人往一个世界写故事只有两条路：
互相改设定（打架），或各存一份副本（分裂）。作品层给第三条：每人一个视图，
世界的账只有一本，审计打在事实层，作品之间天然不冲突。

## 2. 作品卡长什么样

作品是世界仓库里的一等卡（不是另一个目录、不是另一套格式——白拿 id 规则、
审计、git 历史、web 界面）。图景是**维恩图**：事实层是共用底图，每个作品是
套在上面的一只圈——圈与圈共享同一批物品、人物、事件（`canon_refs` 链接），
各画各的弧，互不覆盖。

- 新 `type: work`（契约 0.7；前五种类型是事实层的，work 是视图层的第一个类型）；
- 新字段（全部可选，缺了不判——与 when_sort 同一个 fail-open 哲学）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `view_from` / `view_to` | 数字 | 视图的时间段（与世界流水的 `when_sort` 同一把尺） |
| `pov` | id 列表 | 视角角色（谁的眼睛看这个世界）。**纯宣告，工具不判** |
| `diverges` | id 列表 | 分支声明：本作品故意偏离这些事实卡（红婚让罗柏赢、艾德没死） |
| `part_of` | id 或 null | 章节卡指回所属作品（作品本体为 null）。`type: work` 兼作章节 |
| `knows` | id 列表 | 角色知识声明：这个角色此时知道这些事。**纯宣告，永不机判**（见 §4） |

**章节**：一篇作品 = 一张作品卡 + 若干章节卡（`part_of` 指向它）。章节之间用
`canon_refs` 互相联系（伏笔、呼应、前情）。章节没给 `view_from`/`view_to` 时
继承所属作品的窗口（单跳查找）；作品也没给就不判（fail-open）。
正文体裁不限（小说章节、剧本、跑团记录）。

## 3. 工具管什么（horizon-safe，可严格判定）

**CA801 越窗引用（warning）**：作品卡的 `canon_refs` 引用了**事件卡**，
且该事件的 `when_sort` 落在 `[view_from, view_to]` 窗外 → 报
「这个时间窗外的事，本作品不该引用——要么扩大窗口，要么在 `diverges` 里声明分支」。

- 作品没给 `view_from`/`view_to` → 不判（没声明窗口就没有窗）；
- 被引用的事件没有 `when_sort` → 不判（老规矩，没排序键不猜）；
- 引用的分支目标在 `diverges` 里 → 不响（声明过的偏离是合法创作）；
- `diverges` 指向不存在的 id → CA401（老规矩，结构问题照报）。

**级别为什么是 warning**：越窗可能是笔误（该报），也可能是作者还没写 diverges
（给退路）。error 会把「先写后理」的正常 workflow 拦死。

## 4. 工具不管什么（knowledge，留给作者）

- **知识图谱是宣告，不是计算**：`knows` 字段允许作者写下「这个角色此时知道
  这些事」——可以画成图、可以在界面渲染，但工具**永不机判**（不查「他该不该
  知道」「这份知识来自哪」）。写知识是创作，不是账目；
- 视角内容：这个角色 298 年**该不该知道**某件事——工具算不了，不装会算；
- 分支内部的自洽：罗柏赢了婚礼之后世界怎么走，是作者的叙事责任；
- 作品与作品的冲突：视图之间没有一致性义务。

## 5. 明确不做（v0）

- 作品集装订/多作品合并视图（先不搞多篇——anthology 等真有两篇作品再说）；
- 时间段与真实历法的映射（`when_sort` 是故事内数字，不译公元）；
- `knows` 的任何机判（knowledge-safe 的自动计算，永远不做——那是写作本身）。

## 6. 改动面

- 契约 0.8：`type` 词表 + `work`；`properties` + 六个新字段
  （`view_from`/`view_to`/`pov`/`diverges`/`part_of`/`knows`）；
- `canonlint.py`：VALID_TYPES + work；新规则 CA801（检查点在 check_chain 旁边，
  读 canon_refs 边 + 事件的 when_sort；章节窗口缺失时单跳继承 `part_of` 的窗口）；
- `web/index.html`：作品卡多一个小角标（视图层），台账按层分组；
- 测试：extras 红测试先行（越窗报/声明分支不响/没窗口不判/章节继承窗口/
  diverges 悬空报 CA401/knows 任何写法都不响）；
- 文档：PROTOCOL §2.2 + §6.3 + §9 修订、README/CONTRIBUTING 数字、设计文档 backlog 登记。
