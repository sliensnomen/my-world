# spine/ · 事件脊柱工作区（协议 2.0）

**一句话**：文字世界模型的 L0（事件账本）在这里长出来。宪章见仓库根 `CHARTER.md`；
本文件只管这个目录的纪律与文件清单。

## 分支纪律（2.0 长分支）

1. **只增不改直到切换日**：本分支上 1.x 的代码与六套回归保持全绿，任何让老套件
   变红的改动都是事故。main 保持 1.x 全绿直到切换日（宪章 §4）。
2. **依赖方向条款**（宪章 §4，机器执行）：1.x 代码（`canonlint.py`、`store/`、
   `judges/`、`serve.py`、`econ.py`、`ledger.py`、`classlint/`）不得 import
   `spine/` 的任何模块；`spine/` 侧除迁移工具外不得 import `store/`/`judges/`/
   `canonlint.py`。唯一允许跨界的是单向迁移工具，且只读 `store/parse` 读卡。
   本条由 `spine/tests/` 的 AST 检查执行，不靠自觉。
3. **权威顺序（本分支）**：`spine/event.schema.json`（唯一契约）> 代码 + 测试 >
  `CHARTER.md`。与 1.x 分支的权威序并存，按分支裁定。
4. **永不开第二条写通道**：`spine/` 的写入口只写事件账本；卡面世界只经迁移工具
   单向读入，永不再写。

## 双轨（宪章 §5）

- **读轨（benchmark）**：抽取器——从散文抽候选事件流（锚点 + 置信度），人确认入账。
  第一个里程碑「抽取基准跑通」是读轨的验收门。
- **写轨（创作）**：最小记账界面——巫王世界从这里一笔笔记入。创作轮才算真实使用。
- 两轨不合并验收；本批只立地基，两轨的实现都不在本目录的当前文件里。
